# UBestBeeWear

Artist-designed workwear for people who make things. UBestBeeWear is built around durable, comfortable layers with a considered aesthetic and a clear distinction between everyday workwear and certified personal protective equipment.

## Preview

Open `index.html` in a browser, or serve the repository locally:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
